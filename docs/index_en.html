Air-Gapped Deployment Guide

Deploy quickly in offline environments using a single Docker image

🐳 Single Docker Execution

Go backend and React frontend run inside a unified container.

cp .env.example .env
# Configure environment variables in .env
docker compose up -d

⚙️ 4 Required Environment Variables

Kanvas requires four environment variables to boot.

KANVAS_POSTGRES_DSN=postgres://kanvas:pass@localhost:5432/kanvas
KANVAS_CONFLUENCE_DSN=root:pass@tcp(localhost:3306)/confluence
KANVAS_BOOTSTRAP_ADMIN=admin
KANVAS_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
