## 1. 개요 및 사용자 분류 체계

Kanvas 플랫폼은 사내 5대 핵심 직군(C-Level 경영진, 지식 관리자, 일반 작성 임직원, SRE/DevOps, CISO/보안팀)의 요구사항과 페인 포인트를 정확히 해소합니다.

```
==================================================================================================
                       [Kanvas 5대 핵심 사용자 직군 및 가치]
==================================================================================================
 [1. C-Level 경영진]     ➔ Confluence 고가 라이선스 TCO 75% 절감 및 데이터 원천 소유
 [2. 지식 관리자 / PO]    ➔ Confluence 무중단 안전 마이그레이션 및 Space/Page ACL 관리
 [3. 일반 작성 임직원]    ➔ 초고속 Editor JSON 기반 위키 작성, 버전 히스토리 복원 및 검색
 [4. SRE / DevOps]       ➔ 단일 non-root Docker 컨테이너 및 4대 환경변수 최소 운용
 [5. CISO / 보안팀]       ➔ 100% 사내 오프라인망(Air-Gapped) 구동, Keycloak OIDC & 감사 로그
==================================================================================================
```

## 2. 페르소나별 상세 시나리오 분석

### 2.1 C-Level 경영진 및 본부장
- **Pain Point**: 인원 증가에 따른 Confluence SaaS 라이선스 수수료 폭증 및 외부 클라우드로의 기밀 지식 유출 위험.
- **Kanvas Solution**: 100% 사내 온프레미스 인프라에 단일 Docker로 구성하여 라이선스 비용 75% 절감 및 무중단 이관 실현.

### 2.2 지식 관리자 & Space Manager
- **Pain Point**: Confluence 데이터 이관 시 데이터 손실 및 Space별 권한 매핑 재설정의 번거로움.
- **Kanvas Solution**: Confluence MySQL Discovery와 증거 기반 Migration Machine으로 자동 분류 및 User/Group ACL 이관 처리.

### 2.3 개발자 & AI 클라이언트 (MCP User)
- **Pain Point**: 사내 기술 문서를 찾기 어렵고 AI 도구에서 권한 제어 없이 접근하는 위험.
- **Kanvas Solution**: 8개의 ACL-aware Streamable HTTP MCP Tool을 제공하여 호출자의 보안 권한 범위 내에서만 안전하게 탐색/생성.

## 3. 결론

Kanvas 플랫폼은 경영진의 비용 절감 및 데이터 주권 요구부터 지식 관리자의 이관 안전성, 임직원의 작성 편의성 및 보안팀의 에어갭 컴플라이언스 준수를 전방위로 보장합니다.
