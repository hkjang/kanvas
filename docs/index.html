사내 위키 & 지식 플랫폼

Confluence 데이터 안전 마이그레이션과 원천 데이터 소유권을 하나로

Kanvas는 외부 클라우드 접속이 불가능한 사내 폐쇄망 인프라에서 Confluence의 데이터 구조를 안전하게 분석·마이그레이션하고, PostgreSQL 기반의 초고속 지식 관리 및 8개 ACL-aware MCP 도구 연동을 제공하는 엔터프라이즈 통합 위키 플랫폼입니다.

주요 기능

사내 문서 작성부터 대규모 Confluence 이관 및 AI 통합까지 지원합니다

📑

Wiki Core Engine

Space, Page 트리, 불변 버전 히스토리(Version), 댓글(Comment) 및 구조화 Editor JSON 기반 문서 엔진을 제공합니다.

🔄

Confluence Migration Machine

Read-Only Confluence MySQL Schema Discovery와 Core/AO/Unknown 테이블 분류 및 Cutover Gate 안전 이관을 지원합니다.

🔒

ACL (Space & Page Level)

사용자 및 그룹 단위 읽기/쓰기/관리 권한 제어 엔진을 탑재하여 REST API 및 MCP 도구에 일괄 반영됩니다.

🔐

Keycloak OIDC & 비상 관리자

Keycloak OIDC SSO 연동 및 네트워크 단선 상황을 대비한 로컬 비상 관리자 부트스트랩 계정을 결합했습니다.

🤖

8 ACL-aware MCP Tools

Claude Desktop, Cursor에서 호출자의 위키 권한 범위 내에서 문서를 안전하게 탐색, 검색, 생성, 변경합니다.

📦

오프라인 단일 Docker

Go 모듈러 모놀리스와 React SPA 빌드 자산을 단일 non-root Docker 이미지로 묶어 에어갭 환경에 배포합니다.

Confluence Migration State Machine

최종 승인 후 Kanvas 위키 활성화

개발자 API & 8 ACL-aware MCP Tools

REST API와 Streamable HTTP MCP로 사내 AI 지식 검색을 자동화하세요

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "kanvas_search_pages",
    "arguments": { "query": "Keycloak OIDC SSO" }
  }
}

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Execution

Go 백엔드와 React 프론트엔드가 내장된 단일 컨테이너로 구동합니다.

cp .env.example .env
# .env 환경변수 설정 후 실행
docker compose up -d

⚙️ 4대 필수 환경변수

Kanvas가 사용하는 필수 환경변수는 단 4개입니다.

KANVAS_POSTGRES_DSN=postgres://kanvas:pass@localhost:5432/kanvas
KANVAS_CONFLUENCE_DSN=root:pass@tcp(localhost:3306)/confluence
KANVAS_BOOTSTRAP_ADMIN=admin
KANVAS_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!

자주 묻는 질문 (FAQ)

아닙니다. Kanvas는 Read-Only Confluence MySQL Discovery와 무중단 검증 및 Cutover Gate를 제공하여 서비스 운영 중 안전하게 데이터를 분석하고 전환할 수 있습니다.

네. 프론트엔드 정적 파일과 백엔드 Go 바이너리가 단일 Docker 이미지에 포함되어 있어 외부 CDN 및 네트워크 연결 없이 100% 독립 실행됩니다.

네. Kanvas는 8개의 ACL-aware Streamable HTTP MCP Tool을 제공하여 호출 사용자의 User/Group ACL 권한 범위 내에서만 문서가 검색 및 조작됩니다.
